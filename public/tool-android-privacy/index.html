eTMF扫描王 Android 隐私政策

一、适用范围与联系

本政策适用于 eTMF扫描王 Android App（包名 com.etmfw.scanner，以下简称“本 App”）。本 App 由应用分发页面所列开发者提供。如有隐私问题，请联系 eTMFKing@qq.com。

二、设备上的资料

本 App 无需注册或登录。你导入或扫描的图片、文档、OCR 文字、分类和命名结果、生成的 PDF、试验与中心等工作区记录，在设备本地处理并保存在应用私有空间。命名、导出字段设置及引导完成、隐私同意记录也仅保存在本机。

本 App 没有网络权限，不向开发者上传这些内容、文件元数据或使用遥测，不提供账号、云同步、广告或广告追踪。图片裁剪、文字识别、方向识别及分类建议在本机完成。

仅当你主动分享 PDF、导出 ZIP 或保存导出文件时，所选文件及其中的文档信息才会交给 Android 系统和你选择的目标应用、存储位置或接收方。如果目标为云盘、邮件或其他联网服务，文件可能被该服务上传；后续处理适用目标服务的规则。请在操作前确认资料的保密要求。

三、设备权限与本地组件

相机：仅在你主动拍照扫描时请求，用于获取文档图片。你可在 Android 系统设置中撤销相机权限；撤销后无法使用拍照扫描，仍可使用已有文件及支持的图片导入功能。

相册：使用 Android 系统选图界面，或由系统提供的兼容文件选择器，仅访问你选择的图片，不申请读取整个相册的权限。导出保存通过系统文件创建界面选择位置，不申请广泛存储访问权限。本 App 不申请位置、通讯录、麦克风或电话权限。

文字识别使用随安装包提供模型的 Google ML Kit 中英文 OCR；相机预览使用 CameraX，图像处理使用 OpenCV，方向识别使用随包提供的离线模型。当前版本不通过这些组件将文档发送至开发者或识别服务器，无需下载 OCR 模型即可使用。

四、反馈、网页与第三方渠道

如果你主动通过电子邮件、应用商店或其他渠道反馈问题，你提供的联系信息、文字、截图或附件会经由相应服务处理，并供开发者查看和回复。请勿在反馈中包含患者身份信息、账号密码或其他无权披露的资料。开发者仅为处理反馈和必要的联系使用你主动提供的信息。

应用商店、设备系统对安装、诊断或崩溃等信息的处理适用其各自政策；本 App 不集成向开发者上传崩溃报告或行为分析的服务。

App 内提供随安装包保存的离线政策全文。主动打开网页版时，将调用外部浏览器访问 GitHub Pages，浏览器和 GitHub 可能处理 IP 地址等访问信息，适用其隐私政策。本 App 不会在打开该页面时附带本地文档或工作区数据。

五、保留、删除、备份与安全

本地资料由你在设备上管理，保存至你主动删除、清除应用数据或卸载应用。你可在本 App 中删除文档，也可通过 Android 设置清除全部应用数据。重要资料请先导出，保留原件和独立备份；开发者无法远程查看、恢复或删除设备上的文件。导出或分享产生的临时副本可能保留在应用缓存中，清除应用缓存或应用数据可移除这些副本。

本 App 不提供开发者云备份。当前版本未关闭 Android 系统备份；根据系统版本、设备厂商和你的系统设置，应用数据可能被系统备份或在换机时迁移。该处理由系统或设备服务提供方负责，并适用其规则，不向开发者提供这些文件。请在处理保密资料前核对设备的备份和迁移设置。卸载或删除本机资料不会自动删除系统备份、相册原图或已经导出、分享至其他位置的副本；这些副本需在对应位置另行管理。

应用私有空间利用 Android 的应用隔离机制保护资料；设备丢失、被解锁或系统被破坏仍可能影响安全。请使用系统锁屏并妥善保管设备。

主动提交的反馈不属于本 App 的本地工作区数据。若需咨询、纠正或请求删除直接发给开发者的反馈，请联系上述邮箱；第三方渠道中的数据还需遵循该渠道的处理规则。
