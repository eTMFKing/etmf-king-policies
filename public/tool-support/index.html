开始使用

  1. 在试验目录建立试验与研究中心。
  2. 在相应目录点击右下角扫描入口，选择相机扫描或相册导入。
  3. 复核页面、TMF 分类、版本、日期及命名结果，再保存为 PDF。
  4. 预览或再次编辑已保存文档；批量选择后导出 ZIP 与 CSV 文件清单。

更多操作说明可在 App 内的“设置 → 帮助 → 使用指南”查看。

常见问题

扫描或相册导入无法使用

检查 iOS 设置中的相机权限及系统限制。相机不可用时可尝试从相册导入；请保留尚未保存的页面，避免直接退出导致草稿丢失。

识别或分类结果不准确

在清晰、光照均匀的条件下重新采集，保存前人工确认或修改分类、文件名、版本及日期。识别结果是辅助建议，不替代人工复核。

文件占用较大

在“设置 → 全部文件”选择文档并使用“压缩”。单份压缩可先预览并确认替换；批量压缩前请先备份。完成后检查细字、签字、印章和页序。

怎样备份或交接文件

单份 PDF 可通过系统分享保存到安全位置；批量导出的 ZIP 包含所选 PDF 和 CSV 清单。导出后请在目标位置打开文件，核对数量与内容。请遵守所在机构和项目的保密要求。

无法打开本地资料

先保留当前 App 与设备中的资料，记录错误提示，再尝试页面上的“重试”。不要通过卸载、清除数据或删除备份来排查。若仍失败，请联系开发者；现有资料与可用备份不等于已经成功恢复。

隐私与资料安全

本应用不自动向开发者上传文档、文件元数据或使用遥测。主动分享或导出后，所选目标 App、存储位置及接收方按其自身规则处理资料。

卸载 App 可能移除本地资料。请保留原件，并定期独立备份。本应用用于文档扫描、整理与导出，不提供医疗诊断或治疗建议，也不替代机构的正式归档系统。
